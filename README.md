# 소화 카페 매니저 (모바일)

매장 직원용 모바일 웹앱. 요일별 체크리스트, 발주 요청서 작성, 레시피 북, 직원 교육 문구를 한 화면에서 관리한다.

## 폴더 구조

```
index.html          앱 진입점 (화면 뼈대 · 하단 탭 5개)
css/style.css       디자인 (모바일 레이아웃 · 색 · 폰트)
js/app.js           앱 로직 (화면 그리기 · 체크 · 발주 복사)
data/               콘텐츠 데이터 — 운영 담당자는 여기만 수정
  branches.js       지점 목록
  checklist.js      요일별 체크리스트 + 발주 품목
  recipes.js        레시피
  education.js      직원 교육 · 응대 문구
```

## 탭 구성

| 탭 | 기능 |
|---|---|
| 📊 현황 | 지점 선택, 오늘 진행률 |
| ✅ 체크 | 오픈 / 화장실 / 오후·청소 / 마감 체크 |
| 📦 발주 | 품목 체크 + 수량 메모 → 요청서 텍스트 복사(카톡 전달용) |
| 📖 레시피 | 메뉴별 재료 · 순서 |
| ⚙️ 관리 | 데이터 초기화, 교육 문구 확인 |

## 콘텐츠 수정 방법

- **지점 추가**: `data/branches.js`의 배열에 지점명 추가
- **메뉴 추가**: `data/recipes.js`에 `{ id, name, category, ingredients, steps }` 한 줄 추가 (id는 겹치지 않게)
- **발주 품목 변경**: `data/checklist.js`의 `'발주'` 목록 수정 (이모지로 시작하는 항목은 분류 제목)

> 참고: 체크·메모 기록은 각 기기의 브라우저(localStorage)에 저장된다. 다른 기기와 공유되지 않으며, 수정한 기본 데이터가 기존 기기에 보이지 않으면 ⚙️ 관리 → 데이터 초기화를 실행한다.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages 등 정적 호스팅에 올리면 된다. 빌드 과정 없음.
